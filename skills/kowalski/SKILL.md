# Kowalski

Run this skill in the session that produced the work. Never delegate it.

Checklist:

- necessary
- pragmatic and practical
- safe and secure
- sufficient (nothing missing)
- optimal (best result for the effort)
- minimal (nothing removable without significant loss)
- simple, succinct, precise (content and form: plainest construct, one reading, concrete names)
- discoverable
- reuses what already solves it, fully or partly, here or elsewhere
- preserved (nothing important from the original is lost; no rewording without a clear gain in brevity, simplicity, or precision)

Before Round 1, if the target adds a new function, module, rule, process, or tool, search the repo and the web (e.g. open-source libraries) for full or partial solutions.

Run up to 3 rounds. In each round, run the checklist on the whole current target. Apply the fixes that keep the target's goal and scope; report the rest as suggestions. If no fix was applied, stop.

If Round 3 applied fixes, run the checklist once more and apply no fixes.

Report one line per correction, or "clean", then suggestions and outstanding issues.

Do not commit. The caller decides.
